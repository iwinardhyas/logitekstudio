# Logo Logitek Studio

Tanda `{L_}`: kurung kurawal = kode, **L** = Logika, garis bawah = kursor yang sedang mengetik.
Huruf dari **Plus Jakarta Sans** (L & kursor ExtraBold 800, kurung Regular 400, spasi huruf −3%),
sudah diubah menjadi bentuk (outline), jadi tampil sama tanpa perlu font terpasang. Font berlisensi SIL OFL,
boleh dipakai komersial.

## File

| File | Pakai untuk |
|---|---|
| `logitek-lockup.svg` / `.png` | Logo utama di latar terang: website, kop surat, invoice, proposal |
| `logitek-lockup-gelap.svg` | Latar gelap/navy (kursor teal terang) |
| `logitek-lockup-putih.svg` / `.png` | Satu warna putih: di atas foto, kaos gelap |
| `logitek-lockup-hitam.svg` | Satu warna hitam: fotokopi, stempel, cetak hitam-putih |
| `logitek-mark*.svg`, `logitek-mark.png` | Tanda `{L_}` saja (ruang sempit, avatar) |
| `logitek-icon.svg`, `-512.png`, `-1024.png` | Ikon/avatar media sosial, Google Business, WhatsApp Business |
| `favicon.svg`, `favicon-32.png`, `favicon-16.png` | Ikon tab browser (hanya `L_`, kurung tidak terbaca di ukuran kecil) |
| `apple-touch-icon.png` | Ikon saat website disimpan ke layar utama HP |

## Warna

| Peran | Kode |
|---|---|
| Navy (tanda, teks) | `#1E293B` |
| Teal (kursor, latar terang) | `#0D9488` |
| Teal terang (kursor, latar gelap) | `#2DD4BF` |
| Slate ("studio") | `#475569` |

## Aturan singkat

- Beri ruang kosong di sekeliling logo minimal setinggi huruf **L**.
- Lebar minimum lockup 120 px di layar / 30 mm di cetak; di bawah itu pakai tanda saja.
- Jangan ubah warna kursor menjadi selain teal (atau hitam/putih untuk versi satu warna), jangan
  memiringkan, memberi bayangan, atau meregangkan logo.
- Kursor boleh berkedip di website/animasi; di cetak selalu diam.
